# Manage Google Calendar events by chat with Google Gemini and data tables

### 1. Workflow Overview

This workflow provides a conversational interface for managing a primary Google Calendar using natural language. It interprets user intent via an AI model, manages event operations, and maintains a custom color-categorization mapping stored locally in an n8n data table.

The execution flow is grouped into the following logical blocks:
- **1.1 Input Reception & Setup:** Listens for chat interactions, initializes the storage table for categories if absent, and retrieves primary calendar metadata.
- **1.2 AI Processing & Memory:** Processes user inputs through a conversational Gemini agent equipped with historical memory and a detailed system prompt.
- **1.3 Calendar & Data Tools:** Executes targeted Google Calendar operations (CRUD and color updates) and data table modifications based on the AI agent’s runtime decisions.
- **1.4 Output Handling:** Ensures a guaranteed response is returned to the chat interface, applying a fallback message if the AI output is empty.

---

### 2. Block-by-Block Analysis

#### 2.1 Input Reception & Setup
**Overview:** Captures incoming messages from the chat interface, provisions the custom data table schema on the first run, and queries the Google Calendar API for primary calendar details.

**Nodes Involved:**
- `When chat message received`
- `Create categories table`
- `Get my calendar`

**Node Details:**
- **When chat message received**
  - *Type & Role:* `@n8n/n8n-nodes-langchain.chatTrigger` (Trigger node)
  - *Configuration:* Default chat options.
  - *Connections:* Outputs to `Create categories table`, `Get my calendar`, and `Calendar AI Agent`.
  - *Edge Cases:* Webhook delivery failure or timeout if the trigger source is misconfigured.

- **Create categories table**
  - *Type & Role:* `n8n-nodes-base.dataTable` (Database setup node)
  - *Configuration:* Creates a table named `Categories` containing three string columns: `name`, `colorID`, and `colorName`. Configured with `onError: continueErrorOutput` to bypass execution halts if the table already exists.
  - *Connections:* Input from `When chat message received`. Output is left unconnected.
  - *Edge Cases:* Fails silently if data tables are disabled on the target n8n instance.

- **Get my calendar**
  - *Type & Role:* `n8n-nodes-base.httpRequest` (API integration node)
  - *Configuration:* Sends a `GET` request to `https://www.googleapis.com/calendar/v3/calendars/primary` using predefined Google Calendar OAuth2 credentials.
  - *Connections:* Input from `When chat message received`.
  - *Edge Cases:* Token expiration, permission scope mismatches, or invalid OAuth2 credentials.

---

#### 2.2 AI Processing & Memory
**Overview:** Coordinates the conversational loop by combining an LLM, a sliding window memory buffer, and a strict instruction set to parse user calendar commands.

**Nodes Involved:**
- `Google Gemini Chat Model`
- `Simple Memory`
- `Calendar AI Agent`

**Node Details:**
- **Google Gemini Chat Model**
  - *Type & Role:* `@n8n/n8n-nodes-langchain.lmChatGoogleGemini` (Language model sub-node)
  - *Configuration:* Uses model `models/gemini-3.8-flash` with `maxOutputTokens` set to `10000`. Authenticated via Google Gemini (PaLM) API credentials.
  - *Connections:* Outputs to `Calendar AI Agent` via an AI language model connection.
  - *Edge Cases:* API rate limits, quota exhaustion, or invalid API keys.

- **Simple Memory**
  - *Type & Role:* `@n8n/n8n-nodes-langchain.memoryBufferWindow` (Memory sub-node)
  - *Configuration:* Default buffer window parameters.
  - *Connections:* Outputs to `Calendar AI Agent` via an AI memory connection.

- **Calendar AI Agent**
  - *Type & Role:* `@n8n/n8n-nodes-langchain.agent` (Core AI agent node)
  - *Configuration:* Configured with an extensive system message defining the assistant's persona, current datetime evaluation using `$now.toFormat(...)`, timezone handling, zero-guess rules, category color validation protocols, and instructions to query existing event IDs before updates/deletions.
  - *Key Expressions:* Dynamic evaluation of current time and timezone offset via Luxon expressions (`$now.toFormat(...)`).
  - *Connections:* Inputs from `When chat message received` (Main), `Google Gemini Chat Model` (AI model), `Simple Memory` (AI memory), and multiple calendar/data table tools (AI tools). Outputs to `Fallback reply`.
  - *Edge Cases:* Hallucinated parameter formats, failure to query event IDs before updates, or empty responses generated by the LLM.

---

#### 2.3 Calendar & Data Tools
**Overview:** Exposes external capabilities (Google Calendar operations and n8n data table row manipulations) as tools that the AI agent can invoke dynamically.

**Nodes Involved:**
- `Get events`
- `Create event`
- `Update event`
- `Delete event`
- `Set event color`
- `Get categories`
- `Add category`
- `Delete category`

**Node Details:**
- **Get events**
  - *Type & Role:* `n8n-nodes-base.googleCalendarTool` (AI Tool node)
  - *Configuration:* Retrieves events (`getAll`) from the primary calendar ID obtained via `{{ $('Get my calendar').first().json.id }}`. Parameters (`Limit`, `Before`, `After`) are populated dynamically by the AI via `$fromAI()`.
  - *Connections:* Linked as an AI tool to `Calendar AI Agent`.

- **Create event**
  - *Type & Role:* `n8n-nodes-base.googleCalendarTool` (AI Tool node)
  - *Configuration:* Creates a calendar event with parameters (`Start`, `End`, `Summary`) extracted via `$fromAI()`.
  - *Connections:* Linked as an AI tool to `Calendar AI Agent`.

- **Update event**
  - *Type & Role:* `n8n-nodes-base.googleCalendarTool` (AI Tool node)
  - *Configuration:* Updates an event (`operation: update`) using an `Event_ID`, `Start`, and `End` resolved by the AI.
  - *Connections:* Linked as an AI tool to `Calendar AI Agent`.

- **Delete event**
  - *Type & Role:* `n8n-nodes-base.googleCalendarTool` (AI Tool node)
  - *Configuration:* Deletes a specific event using an `Event_ID` resolved by the AI.
  - *Connections:* Linked as an AI tool to `Calendar AI Agent`.

- **Set event color**
  - *Type & Role:* `n8n-nodes-base.googleCalendarTool` (AI Tool node)
  - *Configuration:* Updates the color property of an event using an `Event_ID` and a Google Calendar color ID (1–11) provided by the AI.
  - *Connections:* Linked as an AI tool to `Calendar AI Agent`.

- **Get categories**
  - *Type & Role:* `n8n-nodes-base.dataTableTool` (AI Tool node)
  - *Configuration:* Retrieves all category records from the `Categories` data table (`operation: get`, `returnAll: true`).
  - *Connections:* Linked as an AI tool to `Calendar AI Agent`.

- **Add category**
  - *Type & Role:* `n8n-nodes-base.dataTableTool` (AI Tool node)
  - *Configuration:* Upserts records (`operation: upsert`) into the `Categories` data table matching on the `name` column with values for `name`, `colorID`, and `colorName`.
  - *Connections:* Linked as an AI tool to `Calendar AI Agent`.

- **Delete category**
  - *Type & Role:* `n8n-nodes-base.dataTableTool` (AI Tool node)
  - *Configuration:* Deletes rows (`operation: deleteRows`) from the `Categories` data table based on the `name` filter condition supplied by the AI.
  - *Connections:* Linked as an AI tool to `Calendar AI Agent`.

---

#### 2.4 Output Handling
**Overview:** Processes the final text output of the AI agent, ensuring a user-friendly fallback response is displayed if the primary output evaluates to empty.

**Nodes Involved:**
- `Fallback reply`

**Node Details:**
- **Fallback reply**
  - *Type & Role:* `n8n-nodes-base.set` (Data transformation node)
  - *Configuration:* Assigns an output string using the expression: `=   {{ $json.output || "Sorry, I didn't understand. Could you give me more details?" }}`.
  - *Connections:* Input from `Calendar AI Agent`.
  - *Edge Cases:* Expression evaluation failures if `$json.output` schema changes unexpectedly.

### 4. Reproducing the Workflow from Scratch

1. **Trigger Setup:**
   - Create a **When chat message received** node (`@n8n/n8n-nodes-langchain.chatTrigger`). Keep default options.

2. **Setup Initialization Nodes:**
   - Add a **Create categories table** node (`n8n-nodes-base.dataTable`). Set resource to `table`, operation to `create`, and table name to `categories`. Define three string columns: `name`, `colorID`, and `colorName`. Configure error handling to continue on fail. Connect its main input to **When chat message received**.
   - Add a **Get my calendar** HTTP Request node (`n8n-nodes-base.httpRequest`). Set URL to `https://www.googleapis.com/calendar/v3/calendars/primary`, authentication to `Predefined Credential Type`, and select your Google Calendar OAuth2 credential. Connect its main input to **When chat message received**.

3. **AI Core Nodes:**
   - Add a **Google Gemini Chat Model** node. Set model name to `models/gemini-3.8-flash`, configure `maxOutputTokens` to `10000`, and assign your Google Gemini API credential.
   - Add a **Simple Memory** node (`@n8n/n8n-nodes-langchain.memoryBufferWindow`) with default settings.
   - Add a **Calendar AI Agent** node (`@n8n/n8n-nodes-langchain.agent`). Paste the system prompt specifying rules, greeting behavior, current time evaluation (`$now`), and category protocols. Connect **Google Gemini Chat Model** to its AI language model input and **Simple Memory** to its AI memory input. Connect the main input from **When chat message received**.

4. **Tool Nodes Configuration:**
   - Add five Google Calendar Tool nodes (`@n8n/n8n-nodes-langchain.googleCalendarTool`):
     - **Get events**: Set operation to `getAll`, calendar ID to `={{ $('Get my calendar').first().json.id }}`, and map limit/time parameters via `$fromAI()`.
     - **Create event**: Set calendar ID to `={{ $('Get my calendar').first().json.id }}`, and map summary, start, and end via `$fromAI()`.
     - **Update event**: Set operation to `update`, calendar ID to `={{ $('Get my calendar').first().json.id }}`, and map event ID, start, and end via `$fromAI()`.
     - **Delete event**: Set operation to `delete`, calendar ID to `={{ $('Get my calendar').first().json.id }}`, and map event ID via `$fromAI()`.
     - **Set event color**: Set operation to `update`, calendar ID to `={{ $('Get my calendar').first().json.id }}`, and map event ID and color via `$fromAI()`.
   - Add three Data Table Tool nodes (`@n8n/n8n-nodes-langchain.dataTableTool`):
     - **Get categories**: Set operation to `get`, `returnAll` to true, and data table name to `Categories`.
     - **Add category**: Set operation to `upsert`, data table name to `Categories`, match on `name`, and map values (`name`, `colorID`, `colorName`) via `$fromAI()`.
     - **Delete category**: Set operation to `deleteRows`, data table name to `Categories`, and filter by `name` via `$fromAI()`.
   - Connect all eight tool nodes to the **Calendar AI Agent** via `ai_tool` connections.

5. **Output Handling:**
   - Add a **Set** node named **Fallback reply**. Configure an assignment with name `output` and value `=   {{ $json.output || "Sorry, I didn't understand. Could you give me more details?" }}`. Connect the main output of **Calendar AI Agent** to this node.
