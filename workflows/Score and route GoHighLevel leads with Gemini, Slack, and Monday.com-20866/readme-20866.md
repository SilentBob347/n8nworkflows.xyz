# Score and route GoHighLevel leads with Gemini, Slack, and Monday.com

### 1. Workflow Overview

This workflow automates the qualification, scoring, and routing of inbound leads originating from GoHighLevel (GHL). It evaluates lead data using Google Gemini, categorizes the lead into a specific tier (Hot, Warm, or Cold), and routes them accordingly to update CRM tags, notify internal teams via Slack, and create task items in Monday.com for high-priority leads.

The architecture is divided into three sequential logical blocks:

- **1.1 Input Reception & Normalization:** Captures incoming lead payloads via webhook, immediately responds to the webhook to close the HTTP connection, defines global environmental variables (such as channel IDs and board IDs), and extracts/normalizes contact details into a clean data structure.
- **1.2 AI Processing & Scoring:** Sends the normalized lead profile to Google Gemini using an AI agent framework configured with a rigid qualification prompt and a Gemini Chat Model. A subsequent code node parses the raw AI response, clamps the score between 1 and 10, and assigns a tier.
- **1.3 Multi-Tier Routing & Execution:** Uses a switch node to branch leads into three distinct execution paths (Hot, Warm, and Cold) based on their tier. Hot leads trigger urgent Slack notifications, GHL tag additions, and Monday.com item creation; Warm leads trigger nurture notifications and tag additions; Cold leads receive automated low-priority tag updates in GHL.

### 2. Block-by-Block Analysis

#### 2.1 Input Reception & Normalization
- **Overview:** Receives raw lead data from GHL, acknowledges receipt immediately, injects configuration parameters, and standardizes lead fields into a unified schema for the AI model.
- **Nodes Involved:** 
  - `Receive GHL Lead Webhook`
  - `Respond to GHL`
  - `Workflow Configuration`
  - `Normalize Lead Fields`
- **Node Details:**
  - **Receive GHL Lead Webhook**
    - *Type & Technical Role:* `n8n-nodes-base.webhook` (Trigger Node)
    - *Configuration:* Listens for incoming `POST` requests on path `ghl-lead-inbound` using a separate response mode (`responseNode`).
    - *Input/Output:* Inputs: None (External Webhook). Outputs: Forwards raw payload to `Respond to GHL`.
    - *Failure Modes:* Network timeout or invalid JSON payloads from GoHighLevel.
  - **Respond to GHL**
    - *Type & Technical Role:* `n8n-nodes-base.respondToWebhook` (Action Node)
    - *Configuration:* Responds with plain text value `OK` to ensure GHL does not timeout waiting for the heavier AI processing steps.
    - *Input/Output:* Inputs: `Receive GHL Lead Webhook`. Outputs: `Workflow Configuration`.
    - *Failure Modes:* Disconnected execution graph if webhook response mode is misconfigured.
  - **Workflow Configuration**
    - *Type & Technical Role:* `n8n-nodes-base.set` (Data Transformation Node)
    - *Configuration:* Assigns constant strings for downstream parameters: `slackHotChannelId`, `slackWarmChannelId`, `mondayBoardId`, `mondayStatusColumnId`, `mondayStatusLabel`, and `companyName`.
    - *Input/Output:* Inputs: `Respond to GHL`. Outputs: `Normalize Lead Fields`.
    - *Failure Modes:* Missing configuration keys will cause evaluation errors in downstream API requests.
  - **Normalize Lead Fields**
    - *Type & Technical Role:* `n8n-nodes-base.code` (JavaScript Execution Node)
    - *Configuration:* Runs once per item. Sanitizes payload variations across GHL contacts and custom fields (handling camelCase, snake_case, or nested arrays).
    - *Input/Output:* Inputs: `Workflow Configuration`. Outputs: `Score Lead with Gemini AI`.
    - *Failure Modes:* Throws JavaScript execution errors if the expected payload structure changes drastically (e.g., missing properties without fallback operators).

#### 2.2 AI Processing & Scoring
- **Overview:** Submits the normalized profile to Google Gemini with strict instructions to evaluate the lead against specific criteria and return a structured JSON score.
- **Nodes Involved:**
  - `Score Lead with Gemini AI`
  - `Gemini Chat Model`
  - `Parse AI Score`
- **Node Details:**
  - **Score Lead with Gemini AI**
    - *Type & Technical Role:* `@n8n/n8n-nodes-langchain.agent` (AI Agent Node)
    - *Configuration:* Uses a system message forcing strict JSON validation and injects dynamic fields from `Normalize Lead Fields` and `Workflow Configuration` into the prompt template.
    - *Input/Output:* Inputs: `Normalize Lead Fields` (main), `Gemini Chat Model` (AI Model link). Outputs: `Parse AI Score`.
    - *Failure Modes:* AI hallucinations, rate limits on the Gemini API, or structural formatting failures in the LLM output.
  - **Gemini Chat Model**
    - *Type & Technical Role:* `@n8n/n8n-nodes-langchain.lmChatGoogleGemini` (Sub-node model provider)
    - *Configuration:* Configured with model name `models/gemini-2.5-flash`.
    - *Input/Output:* Inputs: None. Outputs: Feeds language model data into `Score Lead with Gemini AI`.
    - *Credentials:* Requires a valid Google Gemini (PaLM) API key.
    - *Failure Modes:* Invalid or expired API credentials.
  - **Parse AI Score**
    - *Type & Technical Role:* `n8n-nodes-base.code` (JavaScript Execution Node)
    - *Configuration:* Cleans markdown code fences (` ```json `) from the AI response, extracts JSON, parses the score, clamps it between 1 and 10, and assigns a tier (`Hot`, `Warm`, or `Cold`).
    - *Input/Output:* Inputs: `Score Lead with Gemini AI`. Outputs: `Route by Lead Tier`.
    - *Failure Modes:* JSON parsing errors if Gemini fails to follow formatting constraints, safely handled via fallback objects (`score: 5`).

#### 2.3 Multi-Tier Routing & Execution
- **Overview:** Evaluates the assigned lead tier and fans out execution into paths that alert stakeholders on Slack, apply tags in GoHighLevel, and create tasks in Monday.com.
- **Nodes Involved:**
  - `Route by Lead Tier`
  - `Slack - Hot Lead Alert`
  - `Update GHL - Hot Lead`
  - `Create Monday.com Lead Task`
  - `Slack - Warm Lead Post`
  - `Update GHL - Warm Lead`
  - `Update GHL - Cold Lead`
- **Node Details:**
  - **Route by Lead Tier**
    - *Type & Technical Role:* `n8n-nodes-base.switch` (Flow Control Node)
    - *Configuration:* Evaluates `{{ $json.tier }}` against strings: `Hot`, `Warm`, and `Cold`.
    - *Input/Output:* Inputs: `Parse AI Score`. Outputs: Routes dynamically to respective branch nodes.
  - **Slack - Hot Lead Alert**
    - *Type & Technical Role:* `n8n-nodes-base.slack` (Messaging Node)
    - *Configuration:* Posts an urgent markdown-formatted alert message to the channel ID fetched dynamically from `Workflow Configuration`.
    - *Input/Output:* Inputs: `Route by Lead Tier`. Outputs: `Update GHL - Hot Lead`.
    - *Credentials:* Slack OAuth2 connection required.
    - *Failure Modes:* Incorrect channel ID or revoked OAuth token permissions.
  - **Update GHL - Hot Lead**
    - *Type & Technical Role:* `n8n-nodes-base.httpRequest` (API Request Node)
    - *Configuration:* Sends a `POST` request to `https://services.leadconnectorhq.com/contacts/{contact_id}/tags` adding `['lead-score-hot', 'ai-scored', 'priority-senior-agent']`.
    - *Credentials:* Generic HTTP Header Authentication (Bearer token).
    - *Failure Modes:* Invalid GHL contact ID or expired GHL bearer token.
  - **Create Monday.com Lead Task**
    - *Type & Technical Role:* `n8n-nodes-base.httpRequest` (API Request Node)
    - *Configuration:* Sends a GraphQL mutation to `https://api.monday.com/v2` to create a new board item with status values configured in `Workflow Configuration`.
    - *Credentials:* Generic HTTP Header Authentication (Monday API Token).
    - *Failure Modes:* Invalid board ID, mismatched column ID, or unhandled GraphQL schema changes.
  - **Slack - Warm Lead Post**
    - *Type & Technical Role:* `n8n-nodes-base.slack` (Messaging Node)
    - *Configuration:* Posts a nurture notification to the warm lead channel ID.
    - *Credentials:* Slack OAuth2.
  - **Update GHL - Warm Lead**
    - *Type & Technical Role:* `n8n-nodes-base.httpRequest` (API Request Node)
    - *Configuration:* Sends a `POST` request to add `['lead-score-warm', 'ai-scored', 'nurture-sequence']`.
    - *Credentials:* Generic HTTP Header Auth.
  - **Update GHL - Cold Lead**
    - *Type & Technical Role:* `n8n-nodes-base.httpRequest` (API Request Node)
    - *Configuration:* Sends a `POST` request to add `['lead-score-cold', 'ai-scored', 'low-priority-drip']`.
    - *Credentials:* Generic HTTP Header Auth.

### 4. Reproducing the Workflow from Scratch

Follow these sequential steps to manually rebuild the workflow in n8n:

1. **Create the Webhook Trigger:**
   - Add a **Webhook** node named `Receive GHL Lead Webhook`.
   - Set HTTP Method to `POST`, path to `ghl-lead-inbound`, and Response Mode to `Response Node`.
2. **Add Webhook Response:**
   - Add a **Respond to Webhook** node named `Respond to GHL`.
   - Connect `Receive GHL Lead Webhook` to `Respond to GHL`.
   - Set Response Body to `OK` (Respond with: Text).
3. **Configure Environment Variables:**
   - Add a **Set** node named `Workflow Configuration`. Connect `Respond to GHL` to it.
   - Add assignments for `slackHotChannelId`, `slackWarmChannelId`, `mondayBoardId`, `mondayStatusColumnId`, `mondayStatusLabel`, and `companyName` with appropriate string values.
4. **Normalize Lead Fields:**
   - Add a **Code** node named `Normalize Lead Fields`. Connect `Workflow Configuration` to it.
   - Set mode to `Run Once for Each Item` and paste the JavaScript normalization snippet that extracts standard fields and custom fields from the webhook payload.
5. **Set up AI Scoring Agent:**
   - Add an **AI Agent** node named `Score Lead with Gemini AI`. Connect `Normalize Lead Fields` to its main input.
   - Configure prompt type to define text, embedding the scoring criteria and dynamic fields mapping to `{{ $json.full_name }}`, `{{ $json.budget }}`, etc.
   - Add a **Google Gemini Chat Model** sub-node, configure the model name as `models/gemini-2.5-flash`, and link its AI language model output to the agent. Configure a Google Gemini API credential.
6. **Parse AI Score Output:**
   - Add a **Code** node named `Parse AI Score`. Connect `Score Lead with Gemini AI` to it.
   - Set mode to `Run Once for Each Item` to clean JSON backticks, clamp the score between 1 and 10, and assign the `Hot`, `Warm`, or `Cold` tier.
7. **Create Routing Switch:**
   - Add a **Switch** node named `Route by Lead Tier`. Connect `Parse AI Score` to it.
   - Define 3 output rules where `{{ $json.tier }}` equals `Hot`, `Warm`, and `Cold` respectively.
8. **Build Hot Path:**
   - Add a **Slack** node named `Slack - Hot Lead Alert` connected to the first output of `Route by Lead Tier`. Configure text template and dynamic channel ID assignment using `{{ $('Workflow Configuration').first().json.slackHotChannelId }}`. Add a Slack OAuth2 credential.
   - Add an **HTTP Request** node named `Update GHL - Hot Lead` connected from the Slack node. Method: `POST`, URL: `https://services.leadconnectorhq.com/contacts/{{ $('Parse AI Score').first().json.contact_id }}/tags`. Specify JSON body with hot tags. Configure Generic HTTP Header Authentication (Name: `Authorization`, Value: `Bearer YOUR_GHL_TOKEN`). Add a header parameter `Version: 2021-07-28`.
   - Add an **HTTP Request** node named `Create Monday.com Lead Task` connected from the GHL update node. Method: `POST`, URL: `https://api.monday.com/v2`. Configure GraphQL mutation in the JSON body utilizing board ID, item name, and status configurations from the workflow configuration node. Configure Generic HTTP Header Authentication (Name: `Authorization`, Value: `YOUR_MONDAY_TOKEN`) and header parameter `API-Version: 2024-01`.
9. **Build Warm Path:**
   - Add a **Slack** node named `Slack - Warm Lead Post` connected to the second output of `Route by Lead Tier`. Set channel ID to `{{ $('Workflow Configuration').first().json.slackWarmChannelId }}` using Slack OAuth2 credentials.
   - Add an **HTTP Request** node named `Update GHL - Warm Lead` connected from the Slack node. Method: `POST`, URL pointing to the GHL contact tags endpoint, adding warm tags with the same HTTP Header Auth credential as above.
10. **Build Cold Path:**
    - Add an **HTTP Request** node named `Update GHL - Cold Lead` connected directly to the third output (`Cold`) of `Route by Lead Tier`. Method: `POST`, URL pointing to GHL contact tags endpoint, adding cold/low-priority tags using the GHL HTTP Header Auth credential.
