# Create Monday.com tasks from Fireflies transcripts with Gemini and Slack

### 1. Workflow Overview

This workflow automates the extraction and tracking of meeting action items by integrating Fireflies.ai, Google Gemini, Monday.com, and Slack. Its primary purpose is to convert raw meeting audio transcripts into structured project management tasks and team notifications without manual intervention. The target use cases include automated operations for real estate companies, client service teams, and project managers wanting to eliminate administrative overhead after meetings.

The execution logic is structured into three main blocks:
- **1.1 Input Reception & Configuration:** Listens for incoming transcripts, acknowledges receipt immediately to prevent timeout retries, and initializes global board and channel configurations.
- **1.2 Data Retrieval & AI Processing:** Fetches the transcript payload from Fireflies.ai via GraphQL and utilizes Google Gemini to extract structured task attributes (titles, assignees, deadlines, priorities, and notes).
- **1.3 Task Creation & Notification:** Parses the AI output into discrete items, creates corresponding tasks within Monday.com, aggregates the results, and publishes a formatted recap to Slack.

---

### 2. Block-by-Block Analysis

#### 2.1 Input Reception & Configuration
- **Overview:** Receives webhook notifications when Fireflies.ai finishes processing a transcript, immediately returns an HTTP 200 acknowledgment, and sets up contextual parameters for subsequent integrations.
- **Nodes Involved:** 
  - `Receive Fireflies Webhook`
  - `Respond to Fireflies`
  - `Workflow Configuration`

- **Node Details:**
  - **Receive Fireflies Webhook**
    - *Type & Role:* `n8n-nodes-base.webhook` (Trigger node). Acts as the primary entry point listening for POST requests from Fireflies.ai.
    - *Configuration Choices:* Configured to listen on path `fireflies-transcript-ready` for HTTP `POST` requests using `responseNode` mode.
    - *Expressions:* None.
    - *Connections:* Output connects to `Respond to Fireflies`.
    - *Edge Cases / Failures:* Network dropouts or missing webhook signatures from Fireflies; handled at the platform level.
  
  - **Respond to Fireflies**
    - *Type & Role:* `n8n-nodes-base.respondToWebhook` (Action node). Sends an immediate response back to Fireflies.ai to confirm receipt.
    - *Configuration Choices:* Responds with text content equal to `OK`.
    - *Expressions:* None.
    - *Connections:* Input from `Receive Fireflies Webhook`; output connects to `Workflow Configuration`.
    - *Edge Cases / Failures:* Failure to respond rapidly can cause Fireflies to trigger automated webhook retries.

  - **Workflow Configuration**
    - *Type & Role:* `n8n-nodes-base.set` (Data transformation node). Defines constants used across downstream API calls.
    - *Configuration Choices:* Assigns string values for `mondayBoardId`, `mondayStatusColumnId` (`status`), `mondayDateColumnId` (`date4`), `mondayNotesColumnId` (`text`), and `slackChannelId`.
    - *Expressions:* Static string definitions.
    - *Connections:* Input from `Respond to Fireflies`; output connects to `Fetch Transcript from Fireflies`.
    - *Edge Cases / Failures:* Missing or incorrect IDs will result in failures during Monday.com or Slack API calls.

---

#### 2.2 Data Retrieval & AI Processing
- **Overview:** Queries the Fireflies.ai GraphQL API using the meeting ID extracted from the initial webhook payload, then passes the transcript summary into an AI agent powered by Google Gemini to extract clean action item objects.
- **Nodes Involved:**
  - `Fetch Transcript from Fireflies`
  - `Extract Action Items with Gemini`
  - `Gemini Flash`

- **Node Details:**
  - **Fetch Transcript from Fireflies**
    - *Type & Role:* `n8n-nodes-base.httpRequest` (API integration node). Fetches meeting details from Fireflies.
    - *Configuration Choices:* Sends a POST request to `https://api.fireflies.ai/graphql` with raw JSON body and HTTP Header authentication.
    - *Expressions:* 
      - Uses `{{ $('Receive Fireflies Webhook').item.json.body.meeting_id }}` to dynamically pass the transcript ID to the GraphQL variables.
    - *Connections:* Input from `Workflow Configuration`; output connects to `Extract Action Items with Gemini`.
    - *Credentials Required:* HTTP Header Auth (`Authorization: Bearer <API_KEY>`).
    - *Edge Cases / Failures:* Invalid API keys, expired tokens, or non-existent meeting IDs returned in the webhook payload.

  - **Extract Action Items with Gemini**
    - *Type & Role:* `@n8n/n8n-nodes-langchain.agent` (AI Agent node). Orchestrates prompt processing via a language model.
    - *Configuration Choices:* Configured with a system message establishing the persona of a meeting operations assistant, instructing the model to output *only* a raw JSON array containing keys for `task_title`, `assignee`, `deadline`, `priority`, and `notes`.
    - *Expressions:* 
      - Dynamically injects meeting title, date, action items, overview, and current date (`{{ $now.toFormat('yyyy-MM-dd') }}`) into the prompt text.
    - *Connections:* Main input from `Fetch Transcript from Fireflies`; language model input linked to `Gemini Flash`; output connects to `Parse and Split Action Items`.
    - *Edge Cases / Failures:* Hallucinated outputs or markdown wrapping that fails strict parsing if the model ignores system instructions.

  - **Gemini Flash**
    - *Type & Role:* `@n8n/n8n-nodes-langchain.lmChatGoogleGemini` (Sub-node / Language Model). Provides the underlying LLM capability.
    - *Configuration Choices:* Uses model `models/gemini-2.0-flash`.
    - *Connections:* Connected as the language model dependency for `Extract Action Items with Gemini`.
    - *Credentials Required:* Google Gemini (PaLM) API account (`googlePalmApi`).
    - *Edge Cases / Failures:* API rate limits, quota exhaustion, or service outages on Google AI Studio.

---

#### 2.3 Task Creation & Notification
- **Overview:** Parses the raw text output from Gemini into discrete JSON items, creates tasks sequentially in Monday.com using GraphQL mutations, and consolidates the results into a Slack recap message.
- **Nodes Involved:**
  - `Parse and Split Action Items`
  - `Create Task in Monday.com`
  - `Build Slack Summary`
  - `Send Summary to Slack`

- **Node Details:**
  - **Parse and Split Action Items**
    - *Type & Role:* `n8n-nodes-base.code` (JavaScript execution node). Sanitizes LLM output and maps it into individual items.
    - *Configuration Choices:* Strips markdown code fences (` ```json `), locates JSON array boundaries via string indexing, parses the payload, and outputs individual node items for each task.
    - *Expressions:* Accesses `.output` from the AI agent and transcript details from `Fetch Transcript from Fireflies`.
    - *Connections:* Input from `Extract Action Items with Gemini`; output connects to `Create Task in Monday.com`.
    - *Edge Cases / Failures:* Syntax errors if the LLM output is malformed and lacks standard JSON array brackets.

  - **Create Task in Monday.com**
    - *Type & Role:* `n8n-nodes-base.httpRequest` (API integration node). Creates tasks on a specified board.
    - *Configuration Choices:* Sends a POST request to `https://api.monday.com/v2` using GraphQL mutations.
    - *Expressions:* 
      - Board ID fetched via `{{ $('Workflow Configuration').item.json.mondayBoardId }}`.
      - Item name stringified from `{{ JSON.stringify($json.task_title) }}`.
      - Column values structured with status labels, deadlines, and notes containing assignees and source meeting titles.
    - *Connections:* Input from `Parse and Split Action Items`; output connects to `Build Slack Summary`.
    - *Credentials Required:* HTTP Header Auth (`Authorization: <MONDAY_TOKEN>`).
    - *Edge Cases / Failures:* Column ID mismatches (e.g., `status`, `date4`, `text`), missing status labels ("Not Started"), or expired API tokens.

  - **Build Slack Summary**
    - *Type & Role:* `n8n-nodes-base.code` (JavaScript execution node). Formats the created tasks into a readable markdown recap message.
    - *Configuration Choices:* Loops through all items generated from the split phase, assigns priority icons (`🔴`, `🟡`, `🟢`), and constructs a templated string.
    - *Expressions:* Pulls all upstream items via `$('Parse and Split Action Items').all()`.
    - *Connections:* Input from `Create Task in Monday.com`; output connects to `Send Summary to Slack`.
    - *Edge Cases / Failures:* Empty item arrays if task creation fails downstream.

  - **Send Summary to Slack**
    - *Type & Role:* `n8n-nodes-base.slack` (Messaging integration node). Publishes the meeting recap to a designated Slack channel.
    - *Configuration Choices:* Sends a message using text mode with link unfurling disabled.
    - *Expressions:* 
      - Channel ID retrieved dynamically via `{{ $("Workflow Configuration").item.json.slackChannelId }}`.
      - Message body populated from `{{ $json.slack_message }}`.
    - *Connections:* Input from `Build Slack Summary`.
    - *Credentials Required:* Slack OAuth2 API account.
    - *Edge Cases / Failures:* Invalid channel IDs, bot permission errors, or missing workspace scopes.

### 4. Reproducing the Workflow from Scratch

1. **Create the Webhook Trigger Node:**
   - Add a **Webhook** node named `Receive Fireflies Webhook`.
   - Set HTTP Method to `POST`, path to `fireflies-transcript-ready`, and Response Mode to `responseNode`.
2. **Create the Webhook Response Node:**
   - Add a **Respond to Webhook** node named `Respond to Fireflies`.
   - Set Respond With to `text` and Response Body to `OK`. Connect `Receive Fireflies Webhook` to this node.
3. **Create the Configuration Node:**
   - Add a **Set** node named `Workflow Configuration`.
   - Add assignments: `mondayBoardId` (string, `YOUR_MONDAY_BOARD_ID`), `mondayStatusColumnId` (string, `status`), `mondayDateColumnId` (string, `date4`), `mondayNotesColumnId` (string, `text`), and `slackChannelId` (string, `YOUR_SLACK_CHANNEL_ID`).
   - Connect `Respond to Fireflies` to this node.
4. **Create the Fireflies API Request Node:**
   - Add an **HTTP Request** node named `Fetch Transcript from Fireflies`.
   - Set Method to `POST`, URL to `https://api.fireflies.ai/graphql`, Body Content Type to `Raw` (`application/json`), and Headers to include `Content-Type: application/json`.
   - Configure HTTP Header Auth credentials for Fireflies (`Authorization: Bearer <API_KEY>`).
   - Populate the raw body payload with a GraphQL query requesting `transcript(id: $transcriptId) { id title date summary { action_items overview } }` using variable `transcriptId` set to `{{ $('Receive Fireflies Webhook').item.json.body.meeting_id }}`.
   - Connect `Workflow Configuration` to this node.
5. **Create the Gemini AI Agent & Language Model Nodes:**
   - Add an **Advanced AI Agent** node named `Extract Action Items with Gemini` configured with a `define` prompt type.
   - Set system message: `"You are a meeting operations assistant for a real estate company. Your only job is to extract action items from meeting transcripts and return them as a clean JSON array. Always return valid JSON only — never include markdown fences, explanations, or any text outside the JSON array."`
   - Set prompt text referencing meeting title, date, action items summary, overview, and current date (`{{ $now.toFormat('yyyy-MM-dd') }}`).
   - Add a **Google Gemini Chat Model** sub-node named `Gemini Flash` using model name `models/gemini-2.0-flash`. Link its language model output to the AI Agent. Configure Google Palm API credentials.
   - Connect `Fetch Transcript from Fireflies` to `Extract Action Items with Gemini`.
6. **Create the Parsing & Splitting Code Node:**
   - Add a **Code** node named `Parse and Split Action Items`.
   - Insert JavaScript to strip markdown code fences, parse the JSON array from the agent output, and return individual item objects containing `task_title`, `assignee`, `deadline`, `priority`, `notes`, `meeting_title`, and `meeting_date`.
   - Connect `Extract Action Items with Gemini` to this node.
7. **Create the Monday.com Integration Node:**
   - Add an **HTTP Request** node named `Create Task in Monday.com`.
   - Set Method to `POST`, URL to `https://api.monday.com/v2`, Body Content Type to `Raw` (`application/json`), and Headers to include `Content-Type: application/json` and `API-Version: 2024-01`.
   - Configure HTTP Header Auth credentials for Monday.com (`Authorization: <MONDAY_TOKEN>`).
   - Use a GraphQL mutation for `create_item` mapping `boardId`, `itemName`, and `columnValues` (status label "Not Started", deadline date, and text notes containing assignee and source details).
   - Connect `Parse and Split Action Items` to this node.
8. **Create the Slack Formatting & Notification Nodes:**
   - Add a **Code** node named `Build Slack Summary` to aggregate tasks, assign priority icons (`🔴`, `🟡`, `🟢`), and construct the final markdown message. Connect `Create Task in Monday.com` to this node.
   - Add a **Slack** node named `Send Summary to Slack`. Set resource/action parameters to post text using ID mode for the channel, referencing `{{ $("Workflow Configuration").item.json.slackChannelId }}` and text `={{ $json.slack_message }}`. Configure Slack OAuth2 credentials.
   - Connect `Build Slack Summary` to `Send Summary to Slack`.
