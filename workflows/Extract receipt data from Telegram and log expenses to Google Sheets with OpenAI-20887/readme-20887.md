# Extract receipt data from Telegram and log expenses to Google Sheets with OpenAI

### 1. Workflow Overview

This workflow is designed to automate expense tracking by capturing receipt images sent via Telegram, extracting key transaction details using OpenAI, and logging the structured data directly into a Google Sheets spreadsheet. 

The workflow is organized into four sequential functional blocks:
- **1.1 Input Reception:** Listens for incoming image or document messages sent to a designated Telegram bot and downloads the attached file binary data.
- **1.2 Public Image Hosting:** Uploads the received binary image to an external hosting service to generate a permanent, publicly accessible URL.
- **1.3 AI Data Extraction:** Sends the public image URL to the OpenAI GPT-4.1 mini model with strict prompt instructions to analyze the receipt and extract specific fields in a raw JSON format.
- **1.4 Expense Logging:** Parses the structured JSON response returned by the AI and appends a new row containing the vendor, date, tax, and total amount into a target Google Sheets expense tracker.

### 2. Block-by-Block Analysis

#### 2.1 Input Reception
- **Overview:** This block acts as the entry point for the automation, intercepting user-submitted receipt images or documents in Telegram and preparing the binary file for transmission.
- **Nodes Involved:** `Receive Receipt Photo1`
- **Node Details:**
  - **Type & Role:** `n8n-nodes-base.telegramTrigger` (v1.5) — Triggers the workflow upon receiving a Telegram update and downloads attachments.
  - **Configuration:** Configured to listen for `"message"` updates with the `download` option enabled inside additional fields.
  - **Key Expressions/Variables:** Uses the active Telegram API credential to poll for messages.
  - **Connections:** Input: None (Trigger node). Output: Connects to `Create Public Image Link1`.
  - **Version Requirements:** Telegram Trigger v1.5.
  - **Edge Cases & Failure Types:** Telegram API authentication failure, missing file attachments in messages, or network timeouts during binary download.
  - **Sub-workflow Reference:** None.

#### 2.2 Public Image Hosting
- **Overview:** This block converts the internal binary file from Telegram into a publicly available web URL so that external AI vision models can fetch and process it.
- **Nodes Involved:** `Create Public Image Link1`
- **Node Details:**
  - **Type & Role:** `n8n-nodes-uploadtourl.uploadToUrl` (v1) — Uploads binary data to an external hosting provider.
  - **Configuration:** Expiry type is set to `"never"`.
  - **Key Expressions/Variables:** Automatically consumes the binary file provided by the preceding Telegram trigger node.
  - **Connections:** Input: `Receive Receipt Photo1`. Output: Connects to `AI: Extract Receipt Data1`.
  - **Version Requirements:** UploadToURL node v1.
  - **Edge Cases & Failure Types:** Upload quota exhaustion, unsupported file types, or API downtime on the hosting provider.
  - **Sub-workflow Reference:** None.

#### 2.3 AI Data Extraction
- **Overview:** This block leverages a multimodal large language model to visually inspect the receipt image via its public URL and extract structured accounting data.
- **Nodes Involved:** `AI: Extract Receipt Data1`
- **Node Details:**
  - **Type & Role:** `@n8n/n8n-nodes-langchain.openAi` (v2.3) — Interacts with OpenAI models for text and image analysis.
  - **Configuration:** Resource set to `image`, operation set to `analyze`, model set to `gpt-4.1-mini`. The prompt explicitly instructs the model to return a raw JSON object containing four specific keys (`vendor`, `date`, `amount`, `tax`) without markdown formatting or conversational filler.
  - **Key Expressions/Variables:** `={{ $json.url }}` to reference the image URL generated by the previous node.
  - **Connections:** Input: `Create Public Image Link1`. Output: Connects to `Save to Expense Sheet1`.
  - **Version Requirements:** OpenAI LangChain node v2.3.
  - **Edge Cases & Failure Types:** OpenAI API rate limits, invalid API keys, model hallucinations failing to output valid JSON, or unreadable receipt imagery.
  - **Sub-workflow Reference:** None.

#### 2.4 Expense Logging
- **Overview:** This block parses the text output from the AI model and logs the extracted line items into a cloud-based accounting spreadsheet.
- **Nodes Involved:** `Save to Expense Sheet1`
- **Node Details:**
  - **Type & Role:** `n8n-nodes-base.googleSheets` (v4.7) — Appends new rows to a target Google Sheets document.
  - **Operation:** `append`. Mapping mode is set to define below, targeting columns: `Vendor`, `Date`, `Tax`, and `Total Amount`.
  - **Key Expressions/Variables:**
    - Vendor: `={{ JSON.parse($json['0'].content[0].text).vendor }}`
    - Date: `={{ JSON.parse($json['0'].content[0].text).date }}`
    - Tax: `={{ JSON.parse($json['0'].content[0].text).tax }}`
    - Total Amount: `={{ JSON.parse($json['0'].content[0].text).amount }}`
  - **Connections:** Input: `AI: Extract Receipt Data1`. Output: None (Terminal node).
  - **Version Requirements:** Google Sheets node v4.7.
  - **Edge Cases & Failure Types:** Google OAuth token expiration, spreadsheet schema mismatches, or malformed JSON parsing failures due to unexpected AI text structures.
  - **Sub-workflow Reference:** None.

### 4. Reproducing the Workflow from Scratch

1. **Create the Workflow:** Open n8n and create a new workflow canvas.
2. **Add Telegram Trigger Node:**
   - Add a **Telegram Trigger** node.
   - Set **Updates** to `message`.
   - Under **Additional Fields**, enable **Download** (`download: true`).
   - Configure and select your **Telegram API** credentials.
3. **Add UploadToURL Node:**
   - Add an **Upload To URL** node and connect it to the output of the Telegram Trigger node.
   - Set **Expiry Type** to `never`.
   - Configure and select your **Upload to URL API** credentials.
4. **Add OpenAI Node:**
   - Add an **OpenAI** node and connect it to the output of the Upload To URL node.
   - Set **Resource** to `Image` and **Operation** to `Analyze`.
   - Select the model: `gpt-4.1-mini`.
   - Set the **Image URLs** expression to: `={{ $json.url }}`
   - Populate the **Text** parameter prompt with instructions to extract `"vendor"`, `"date"` (YYYY-MM-DD), `"amount"` (number only), and `"tax"` (number only, default 0 if missing) strictly as a raw JSON object without markdown wrappers.
   - Configure and select your **OpenAI API** credentials.
5. **Add Google Sheets Node:**
   - Add a **Google Sheets** node and connect it to the output of the OpenAI node.
   - Set **Operation** to `Append`.
   - Set **Document ID** using the target Google Sheet URL.
   - Set **Sheet Name** to your desired sheet tab (e.g., `Sheet1`).
   - Set **Mapping Mode** to `Define Below`.
   - Map the sheet columns using the following expressions:
     - **Vendor:** `={{ JSON.parse($json['0'].content[0].text).vendor }}`
     - **Date:** `={{ JSON.parse($json['0'].content[0].text).date }}`
     - **Tax:** `={{ JSON.parse($json['0'].content[0].text).tax }}`
     - **Total Amount:** `={{ JSON.parse($json['0'].content[0].text).amount }}`
   - Configure and select your **Google Sheets OAuth2 API** credentials.
6. **Finalize and Test:** Ensure all credentials validate successfully, activate the workflow, and send a test receipt image to your Telegram bot.
